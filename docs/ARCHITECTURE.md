# 架构

浏览器采集麦克风并转为 16kHz 单声道 PCM，通过本机 WebSocket 发送。后端同时写入 WAV，并对用于识别的音频做有上限的增益。WhisperLiveKit + faster-whisper/CTranslate2 使用 LocalAgreement 输出英文初稿与确认内容。

确认内容由 SentenceBuffer 合并，保存到 SQLite。单独的翻译队列通过本机 llama.cpp 服务运行 HY-MT1.5，补齐中文；翻译失败保留原文与错误状态，可重试。课程背景和术语只用于翻译提示。

每堂课由独立 ID 关联名称、字幕、任务和录音。结束时关闭录音并刷新尾部字幕，中文队列继续处理。删除要求显式确认，并先处理录音文件，再删除数据库内容，避免文件失败后误报成功。列表通过请求和页面状态变化同步。

服务仅监听 `127.0.0.1:8766`；翻译子进程监听 `127.0.0.1:8767`，使用每次启动生成的本地随机密钥。密钥、日志和数据只写入忽略目录。请勿将本服务直接暴露到公网。

源码发布与本机正在使用的安装目录分开。运行中的课堂程序和其历史未因发布整理而移动或清空。
